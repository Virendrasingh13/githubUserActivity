# githubUserActivity

This is my first Java Spring Boot backend project.

## What this project has
- A basic Spring Boot backend setup
- One REST API endpoint: `GET /api/welcome`

## How to run
1. Make sure Java 17+ and Maven are installed.
2. Run:
   ```bash
   mvn spring-boot:run
   ```
3. Open:
   - `http://localhost:8080/api/welcome`

## Run tests
```bash
mvn test
```
